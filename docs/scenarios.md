# Demo Scenarios: specification

The 13 polished demo scenarios. Each is **configuration** over the shared shock model (see `CURSOR_BUILD_PROMPT.md` §B.4). Parameters marked ★ are the live sliders a CFO can change in the meeting. All data is synthetic.

Shock types: `node_down`, `lane_down`, `supplier_capacity`, `demand_multiplier`, `cost_multiplier`, `market_block`, `temperature_loss`, `lead_time_shift`, `batch_quarantine`, `price_change`.
Levers (prescription): `transfer`, `alternate_lane`, `alternate_supplier`, `expedite`, `prebuild`, `allocation_priority`, `safety_stock_raise`, `backup_power`, `spot_buy`.

## Presenter flow (hero path)
1. **Executive page:** resilience score 62/100; top risk "China ingredient dependency, ₹186 cr".
2. Open **Monsoon + dengue** (cached result loads instantly). Walk through **Money | Service**.
3. CFO moves ★ flood duration from 10 to 15 days and presses Re-run. Progress bar → updated numbers in under 60 s.
4. **Compare plans:** Cost-optimal vs Service-optimal vs Balanced (recommended). Explain "why this plan".
5. **Send for approval** → Approval queue → approve with reason → audit entry.
6. Ask the copilot: "What if we also lose the Chennai port for a week?" → it proposes a compound scenario card → run.
7. Close on **Stress test** heatmap: "Here's where to spend on resilience."
